# 💪 Workout Generator

A simple Python program that generates random workouts using exercises from three categories: **Core, Arms, and Legs**.

## Features

- 🎲 Generates random workouts.
- 🏋️ Includes three exercise categories.
- 🔢 Lets you choose how many exercises per section.
- 🔄 Simple menu to generate workouts or exit.

## Requirements

- Python 3
- `excercizes.txt` exercise file

## How to Run

1. Download or clone this repository.
2. Make sure `main.py` and `excercizes.txt` are in the same folder.
3. Run the program:

```bash
python main.py
```

## How to Use

Choose an option from the menu:

- **1** — Generate a random workout.
- **2** — Change the number of exercises per section.
- **3** — Exit the program.
